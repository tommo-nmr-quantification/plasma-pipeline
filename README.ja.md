# ToMMo NMR Quantification：50化合物の定量・データ整備

処理は **BINの切り出し → 特徴量 → 濃度 → 10SD除外 → 低値除外** です。

[実行手順](docs/setup.md) · [全50項目の列番号・モデル表](config/model_columns.tsv) · [化合物別の追加対応メモ](docs/curation.md)

## 同じ列番号の定義を全化合物に使う

入力は「ID列＋37,000列のスペクトル強度」です。共通のppmヘッダーに対して、化合物ごとの開始・終了BINを固定しています。

一覧表の `TSV_first_column_1based` / `TSV_last_column_1based` は、**IDを第1列として数えた、元TSVの列番号**です。両端を含みます。全50項目を同じ形式で記載し、実際のppm、最大値／BIN総和などの特徴量、係数・切片も併記しています。

コードではIDを除いたスペクトルを0始まりで数え、`spectrum[bin_start:bin_end + 1]` で共通に切り出します。対応式は **元TSVの列番号 = BINインデックス + 2** です。

通常の線形モデル45項目、MLP4項目、TCN000042の特徴量補正を伴う単一線形モデル1項目を適用します。Succinateの参照領域差し引き、MLPのベクトル入力、TCN000042の自動モード判定も共通パイプラインから呼び出します。

## 濃度を出した後の処理

1. 必要なバッチ補正を反映した濃度に対し、別途指定した基準集団の **平均±10SDの外側**をNAにします。境界と等しい値は残します。
2. 残った値のうち、化合物ごとの**運用上の下限値以下**をNAにします。

基準の平均・SDは、同梱の [全50項目の統計表](config/reference_stats.tsv) を既定で使用します。小数2桁で記載された値から除外境界を計算し、入力検体から計算し直すことはありません。10SD除外後の表、最終表、除外理由を保存するため、各段階の処理を追跡できます。性能評価や教師データの詳細は論文側で扱います。

まず [実行手順](docs/setup.md) の人工データの例で、50項目を一括処理できます。
